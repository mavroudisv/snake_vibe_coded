# Snake Game

A simple Snake game created with Python and Pygame.

## Requirements

- Python 3.x
- Pygame

## Installation

1. Make sure you have Python installed. If not, download and install it from [python.org](https://python.org).
2. Install Pygame using pip:
```
pip install pygame
```

## How to Run

Run the game by executing:
```
python snake_game.py
```

## How to Play

- Use the arrow keys (Up, Down, Left, Right) to control the snake's direction
- Eat the red food to grow the snake and increase your score
- Avoid hitting the walls or the snake's own body
- If you lose, press 'C' to play again or 'Q' to quit

## Game Features

- Score tracking
- Game over screen with restart option
- Increasing snake length
